# ``JavaScriptCoreKit``

Evaluate JavaScript programs from within an app, and support JavaScript scripting of your app

## Overview

The JavaScriptCoreKit provides the ability to evaluate JavaScript programs from within Swift and C-based apps. You can use also use JavaScriptCoreKit to insert custom objects into the JavaScript
environment.
